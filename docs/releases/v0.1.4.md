# Binturong v0.1.4

This release adds a Windows portable download and updates Rust dependencies to
address security advisories. The tool registry still contains 134 tools.

## Changes

- Add `Binturong_0.1.4_windows-x64-portable.zip`, containing the desktop app,
  CLI, instructions, and license. Extract the entire ZIP and launch the app
  without installing Binturong. WebView2 must already be installed; saved data
  remains in your user profile.
- Check the extracted Windows portable CLI's version and JSON-to-YAML conversion
  in the release workflow before uploading it with the installers and checksums.
- Update rustls, zip, and related locked dependencies to address dependency
  security advisories.

## Installation

Use the [installation guide](../../README.md#install) to choose the universal
macOS ZIP/DMG, Windows x64 EXE/MSI or portable ZIP, or Linux x86_64
DEB/RPM/AppImage. Release assets include `SHA256SUMS`; see the
[checksum instructions](../releasing.md#download-integrity).

macOS builds remain ad-hoc signed and unnotarized. Windows builds have no
publisher signature. OCR requires a separate Tesseract installation. Automatic
updates are unavailable; install the new release manually or use Homebrew after
the independent tap updates its cask. Winget, Snap, and Flatpak candidates remain
unpublished.

See the [v0.1.4 local validation record](v0.1.4-validation.md) for automated
checks and platform limits. The release workflow must build and test all three
platforms before publishing the complete asset set.
