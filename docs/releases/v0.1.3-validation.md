# v0.1.3 local validation — October 5, 2026

Scope: the v0.1.3 release candidate following `83db917` on one macOS Apple Silicon
host. These results describe local checks; they do not establish clean-machine
installation, upgrade, removal, or native Windows/Linux validation.

## Automated QA

The [release-candidate QA script](../../scripts/release_candidate_qa.sh) passed:

- Production frontend build.
- 105 UI tests across 19 files.
- Privacy/security source checks.
- Dependency/license audit: zero reported vulnerabilities, 681 Rust packages,
  seven npm production packages, and 58 bundled assets checked. Cargo audit also
  reported nine unmaintained and nine unsound warnings.
- 92 Rust tests: 71 unit tests, five CLI tests, ten Markdown-conversion tests,
  and six Word Frequency Counter tests.
- CLI registry count: 134 tools.
- All six performance checks, including OCR with installed English data.

The version checker confirms matching npm, npm-lockfile, Cargo, Cargo-lockfile,
and Tauri versions. The root Cargo check passed. See the
[release runbook](../releasing.md) for CI, installer, and publication gates.

## Universal macOS package

The locked universal macOS installer build passed. Checks against the mounted
v0.1.3 DMG confirmed:

- App metadata reports v0.1.3.
- The app executable and bundled CLI both contain arm64 and x86_64 architectures.
- Deep, strict code-signature verification passes for the ad-hoc signed app.
- Both CLI architectures report `binturong-cli 0.1.3`, list 134 tools, and format
  a synthetic JSON object correctly. The x86_64 checks ran through Rosetta on
  this Apple Silicon host; they do not establish native Intel Mac installation.

The [asset collector](../../scripts/collect_release_assets.py) checked the DMG's
universal CLI and produced the universal installation ZIP with the quarantine
helper and instructions. Local assets and a Mac-only checksum file are stored in
`/tmp/binturong-v0.1.3-release/`; this temporary path is not a published download.
