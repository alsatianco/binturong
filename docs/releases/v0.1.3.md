# Binturong v0.1.3

This release fixes saving pipelines on macOS and improves the workspace, text
outputs, and Word Frequency Counter. The tool registry still contains 134 tools.

## Changes

- Replace browser prompts and confirmations with in-app dialogs. Saved chains
  can be named, saved, renamed, and deleted; history clearing also uses these
  dialogs.
- Respect the selected theme in the pipeline tool selector and keep saved-chain
  action buttons inside their cards.
- Add a remembered main-menu visibility toggle. Sidebar-search shortcuts and
  Home tool-group navigation reveal the menu when needed.
- Center Home and adapt its tool grids to the available workspace width.
- Improve text-diff headers and inline change highlights.
- Automatically size text output boxes up to 45 lines and allow vertical resizing.
- Add word, character, sentence, paragraph, and space counts, estimated reading
  level, reading time, and speaking time to Word Frequency Counter. The statistics
  also appear in its JSON output for CLI and batch use.
- Expand installation instructions, CLI examples, privacy documentation, and
  workflow demonstrations.

## Installation

Use the [installation guide](../../README.md#install) to choose the universal macOS
ZIP/DMG, Windows x64 EXE/MSI, or Linux x86_64 DEB/RPM/AppImage. Release assets include
`SHA256SUMS`; see the [checksum instructions](../releasing.md#download-integrity).

macOS builds remain ad-hoc signed and unnotarized. Windows installers have no
publisher signature. OCR requires a separate Tesseract installation. Automatic
updates are unavailable; install the new release manually or use Homebrew after
the independent tap updates its cask. Winget and Flatpak candidates in this
repository still target v0.1.2 and are unpublished.

The pipeline dialog fix passed native macOS persistence checks before this
release; those [dated results](../installation-validation-2026-10-03.md) do not
establish v0.1.3 installer validation on Windows, Linux, or both Mac architectures.
The [v0.1.3 local validation record](v0.1.3-validation.md) records this candidate's
automated checks and platform limits.
