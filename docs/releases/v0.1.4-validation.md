# v0.1.4 local validation — October 17, 2026

Scope: the v0.1.4 release candidate following `54959d2` on one macOS Apple Silicon
host running macOS 26.6.2. These results describe local checks; they do not establish
clean-machine installation, upgrade, removal, or native Windows/Linux validation.

## Automated QA

The [release-candidate QA script](../../scripts/release_candidate_qa.sh) passed:

- Production frontend build.
- 105 UI tests across 19 files.
- Privacy/security source checks.
- Dependency/license audit: zero reported vulnerabilities, 682 Rust packages,
  seven npm production packages, and 58 bundled assets checked. Cargo audit also
  reported ten unmaintained and nine unsound warnings, with no yanked packages.
- 92 Rust tests: 71 unit tests, five CLI tests, ten Markdown-conversion tests,
  and six Word Frequency Counter tests.
- CLI registry count: 134 tools.
- All six performance checks, including OCR with installed English data.

| Performance check | Target | Local measurement |
| --- | --- | --- |
| Search results | 50 ms | 0.26 ms p95 |
| Input detection | 200 ms | 0.85 ms p95 |
| Typical formatter/encoder input | 50 ms | 0.09 ms p95 |
| SHA-256 of a 100 MB file | 5,000 ms | 1,099.38 ms |
| Image conversion | 3,000 ms | 38.23 ms p95 |
| OCR | 10,000 ms | 465.83 ms |

The version checker passed with `GITHUB_REF_TYPE=tag GITHUB_REF_NAME=v0.1.4`,
confirming matching npm, npm-lockfile, Cargo, Cargo-lockfile, Tauri, and tag
versions. The root Cargo check passed. See the [release runbook](../releasing.md)
for CI, installer, and publication gates.

## Universal macOS package

The locked universal macOS installer build passed. Checks against the mounted
v0.1.4 DMG confirmed:

- App metadata reports v0.1.4.
- The app executable and bundled CLI both contain arm64 and x86_64 architectures.
- Deep, strict code-signature verification passes for the ad-hoc signed app.
- Both CLI architectures report `binturong-cli 0.1.4`, list 134 tools, and convert
  a synthetic JSON object to YAML correctly. The x86_64 checks ran through Rosetta
  on this Apple Silicon host; they do not establish native Intel Mac installation.

The [asset collector](../../scripts/collect_release_assets.py) checked the DMG's
universal CLI and produced the universal installation ZIP with the quarantine
helper and instructions. The ZIP passed its integrity and contents checks. Local
assets and a Mac-only `SHA256SUMS` are stored in `/tmp/binturong-v0.1.4-release/`;
this temporary path is not a published download.

## Publication status at preparation

This candidate was prepared locally. Publication requires pushing the reviewed
commit and version tag; no push was performed during preparation. GitHub Actions
must build and test all three platforms before publishing the complete asset set.
Windows portable extraction, CLI checks, and GUI smoke tests were not run on this
macOS host. Clean-machine testing on both Mac architectures remains separate
from these automated checks.
