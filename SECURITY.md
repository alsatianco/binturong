# Security reporting

For a suspected vulnerability, use GitHub's **Security → Report a vulnerability**
if that option is available in [this repository](https://github.com/alsatianco/binturong/security).
Otherwise contact the maintainer through the [author profile](https://www.linkedin.com/in/ducnd87/)
to arrange a private reporting channel. Private reporting availability and
response times are not guaranteed by this document.

Include the version, platform, affected tool or integration, reproduction steps,
and impact. Use synthetic inputs. Avoid publishing credentials, private data, or
exploit details in a public issue while a private report is being arranged.
Ordinary bugs can be reported through [Issues](https://github.com/alsatianco/binturong/issues).

The latest stable release is the target for fixes. The project does not currently
promise a separate long-term support window for older releases. For data handling
and retention, see [privacy](docs/privacy.md); for signing and downloaded-artifact
verification, see the [release runbook](docs/releasing.md#download-integrity).
